# Neo‑Minimal Task Manager

A crisp, React + Tailwind task manager built with Neo‑Minimalism design principles.

## Features
- Add tasks (click or Enter key)
- Toggle completion (checkbox or click text)
- Delete tasks (hover‑revealed trash icon)
- Filter: All / Active / Completed
- localStorage persistence
- Fully responsive

## Run Locally
1. Clone the repo
2. npm install && npm run dev
3. Open http://localhost:5173
